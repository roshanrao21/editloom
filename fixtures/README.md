# Editloom pilot fixtures

This directory deliberately contains no media files. The Phase 0 inventory and acceptance expectations are in [the technical-boundaries plan](../docs/phase-0-v1-boundaries.md).

When the application workspace is introduced, add a machine-readable `manifest.json` that records each approved pilot fixture's ID, provenance, permission or license, technical metadata, checksum, and expected test outcomes. Do not commit source media unless its license and repository size policy both permit it.
